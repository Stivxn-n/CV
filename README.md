## Sobre este repositorio

Hoja de vida web de una página, hecha con HTML, CSS y JavaScript sin dependencias.
Incluye tema oscuro, animaciones, modo matrix y una versión imprimible.

- **Sitio publicado:** https://stivxn-n.github.io/CV/
- **Archivos:** `index.html` · `css/` · `js/` · `assets/`
- **Imprimir o guardar en PDF:** `Ctrl + P`; `css/print.css` adapta el diseño a papel.
- **Foto:** `assets/foto.jpg`; el encuadre se ajusta con `object-position` en
  `css/components.css`.
